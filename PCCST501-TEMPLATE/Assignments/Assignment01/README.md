Assignment 01

How the Internet Delivers a Web Page 

## objective
To understand how a web page is delivered over the Internet by studying the roles of the TCP/IP protocol stack, DNS, HTTP, TCP, client-server architecture, cookies, 
and comparing HTTP with FTP using Google as an example

## Solution
The assignment explains the complete process that occurs when a user enters www.google.com into a browser. It describes how DNS resolves the domain name into an IP 
address, how HTTP sends requests and receives responses, how TCP ensures reliable communication, the functions of each TCP/IP layer, the client-server architecture,
the differences between HTTP and FTP, and the role of cookies in improving the user experience

## Output
The study demonstrates the complete communication process involved in loading a web page. It shows how different Internet protocols and network layers work together
to provide secure, reliable, and efficient web communication, allowing users to access websites quickly and seamlessly.

## Conclusion
This assignment provides a clear understanding of how Internet communication takes place when accessing a website. It highlights the importance of application-layer
protocols, DNS, TCP/IP, and the client-server model in enabling reliable web services. Overall, it demonstrates that these networking technologies work together to
ensure fast, accurate, and efficient communication between users and web servers.
